# aclnnPluginOperation-ATBOperation Graph Sample

## Introduction

This case is a sample of running a graph combining aclnnPluginOperation and ATBOperation. This case consists of five parts: aclnn operator, ATB operator, model, infrastructure, and main function.

- aclnn operator: Implements the integration of the ATB.
- ATB operator: Builds an ATB graph operator.
- Model: The ATB operator and the operators generated by the aclnn operator are used to build a larger graph operator, and the call logic related to the ATB graph operator is included.
- Infrastructure: Includes logs and memory pools, which help locate faults and accelerate graphics memory allocation.
- Main function: Carries the function of the program entry. In addition, the multi-thread function is implemented in the main function.

## Case Execution

- Go to the `atb-aclnn` directory.

    ```sh
    cd  ${Case directory}/atb-aclnn
    ```

- Set the CANN environment variable, for example, source /usr/local/Ascend/ascend-toolkit/set_env.sh.

    ```sh
    source ${Toolkit installation directory}/set_env.sh
    ```

- Set the ATB environment variable, for example, by running `source /usr/local/Ascend/nnal/atb/set_env.sh`.

    ```sh
    source ${NNAL installation directory}/atb/set_env.sh
    ```

- Execute the `build.sh` script.

    ```sh
    bash ./build.sh
    ```

- Execute the test case.

    ```sh
    ./build/test_model
    ```

## Remarks

- In the current case, threads are created based on the number of devices on the physical machine. If you need to adjust the number of threads, change the number of threads created in `main.cpp`.
- Ensure that the ABI version of the demo is the same as that of the ATB. To view the ABI version of the ATB, perform the following steps:

    ```sh
    env | grep ATB_HOME_PATH
    ```

    To check the ABI version of the demo, run the following command in CMakeList to check whether the ABI version is 0 or 1. `OFF` indicates 0, and `ON` indicates 1. The following code indicates that the ABI version is 0.

    ```sh
    option(USE_CXX11_ABI "USE_CXX11_ABI" OFF)
    ```
